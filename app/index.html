    or paste an iCal address

    Where do I find that address?
    • Google Calendar — Settings → your calendar → Integrate calendar → Secret address in iCal format.
    • Outlook / Microsoft 365 — Settings → Calendar → Shared calendars → Publish a calendar → choose ICS.
    • Apple iCloud — Calendar on iCloud.com → share icon beside the calendar → Public Calendar → copy the link.

    Treat this address like a password — anyone holding it can read that calendar. It is never shown again once saved, and only the sync server can read it back. You can revoke it at any time from your calendar provider, which immediately makes the old address useless.
